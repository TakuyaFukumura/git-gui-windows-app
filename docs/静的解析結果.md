## 対応が必要な指摘

### 1. 未使用のメソッド引数

- **場所**: `src/main/java/com/example/gitguiwindowsapp/git/GitStatusParser.java:41`
- **検出**: PMD `UnusedFormalParameter`（Priority 3）
- **内容**: `typeOf(char x, char y, String path)` の `path` 引数がメソッド内で使用されていない。
- **対応案**: `path` 引数を削除し、呼び出し側も `typeOf(x, y)` に変更する。
- **影響**: 動作への影響はないが、不要な引数が残ることでメソッドの責務とシグネチャが不明確になる。

### 2. unchecked コンパイラー警告

- **場所**: `src/main/java/com/example/gitguiwindowsapp/ui/ChangesPane.java`
- **検出**: `javac -Xlint:unchecked`
- **内容**: JavaFX のテーブル設定箇所で unchecked 警告が発生している。通常のコンパイルは成功するが、型安全性をコンパイラーで確認できない箇所が残っている。
- **対応案**: 警告の詳細な発生式を特定し、JavaFX のジェネリック型を明示して警告を解消する。抑制アノテーションによる隠蔽は避ける。
- **影響**: 現時点でテストは通過しているが、誤った型の値を扱う変更をコンパイラーが検出できない可能性がある。
