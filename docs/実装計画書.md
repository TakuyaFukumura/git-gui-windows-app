# Git GUI Windows App 実装計画書

## 1. 実装済み

- メッセージ管理画面、DAO、SQLite JDBC、入出力・バックアップ機能を削除
- `GitCommandRunner` と Git 実行結果・例外モデルを追加
- `GitStatusParser`、`GitDiffParser`、`GitBranchParser` を追加
- Repository、FileChange、Branch、Diff の不変モデルを追加
- `GitService` にリポジトリ検証、status、diff、stage、unstage、commit、
  branch list/create/switch/delete を実装
- Git リポジトリを選択できる JavaFX 画面、変更一覧、差分表示、主要操作を実装
- Git 実行ファイルと最近のリポジトリ5件を Properties に保存
- runner、パーサー、サービス検証、設定の JUnit テストを追加
- ブランチ名を Git の `check-ref-format` で検証
- 未コミット変更を確認するブランチ切り替えダイアログ
- マージ済みブランチだけを削除できる安全な削除 UI と確認ダイアログ

## 2. 残作業

### Phase 5: 設定と操作性

- Git 実行ファイルを変更する設定画面を追加する
- 前回リポジトリが開けない場合の選択画面を改善する
- 処理中の進捗表示、多重実行防止、キーボードショートカットを拡充する
- diff の行種別表示、選択状態、アクセシビリティを改善する

### Phase 6: 高度な Git 機能

- リモート、履歴、タグ、stash、部分ステージを検討する
- コンフリクト検出と外部ツールへの委譲導線を追加する
- 大規模リポジトリでのキャンセル・出力制限を強化する

### Phase 7: 配布と手動確認

- jpackage の Windows アプリケーションイメージを検証する
- Windows 10/11 のクリーン環境で Git 未導入・権限エラーを確認する
- README に配布手順と対象外機能を反映する

## 3. 設計上の方針

- UI から `ProcessBuilder` を直接呼ばず、`GitService` 経由で操作する。
- Git の機械可読出力（porcelain、format）を優先し、人間向け文言を解析しない。
- ファイルパスやコミットメッセージはシェル文字列に連結しない。
- Git 処理は JavaFX アプリケーションスレッド外で実行する。
- Git の失敗を成功扱いせず、終了コードと stderr をユーザーに伝える。

## 4. 完了判定

- `mvnw.cmd clean install` が成功する。
- メッセージ管理・SQLite の実装と依存関係が残っていない。
- リポジトリ検証、status、diff、stage、unstage、commit、基本的な安全なブランチ操作が UI から利用できる。
- README と本書の進捗が実装状態と一致する。
