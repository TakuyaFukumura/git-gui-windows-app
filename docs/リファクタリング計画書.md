# Git GUI Windows App リファクタリング残作業計画書

> 更新日: 2026-09-10
> 状態: **GUI手動確認のみ未完了**

## 1. 目的

本書は、リファクタリングに関して現時点で未完了の作業だけを記録する。完了済みの層分離、UI分割、Parserとモデルの契約強化、設定カテゴリの分離、テスト整理は記載しない。

機能追加やUIデザインの刷新は対象外とし、リファクタリング前後でユーザーが認識できる動作に差がないことを確認する。

## 2. 未完了作業

### Step 8: GUI環境での回帰確認

#### 対象

`mvnw.cmd javafx:run` または `mvn javafx:run` でアプリケーションを起動し、主要な画面操作を手動で確認する。

#### 確認項目

- リポジトリ選択と切り替え
- 変更一覧と差分表示
- ファイルのステージ・アンステージ
- コミット
- ブランチの作成・切り替え・削除
- コミット履歴の表示と検索
- テーマ切り替え
- 終了時の設定保存と、次回起動時の状態復元

#### 完了条件

- 上記の操作がGUI上でエラーなく完了する。
- リファクタリング前からの既存動作に、ユーザーが認識できる差異がない。
- ウィンドウのリサイズと終了が正常に動作する。

#### 実施方法

1. GUI環境で`mvnw.cmd javafx:run`または`mvn javafx:run`を実行する。
2. 確認項目を順に操作し、結果を記録する。
3. 問題が見つかった場合は、原因調査と修正を本計画とは別の変更として扱う。

## 3. 完了済みとして扱う範囲

以下は完了済みのため、本書の未完了作業には含めない。

- Step 6: Parserとモデルの入力契約の強化
- Step 7: 設定のカテゴリと責務の分離
- Step 8: テスト構成と移行後のコードの整理
- `mvnw.cmd clean install`によるビルドとテスト
- Gitコマンドの安全な引数分離と既存設定ファイルの互換性の維持

## 4. 共通制約

- `GitGuiWindowsApp`はJavaFXのライフサイクルとサービス配線に限定する。
- UI以外のクラスからJavaFXコントロールを参照しない。
- `model`と`application`はJavaFX型に依存しない。
- Gitコマンドはシェルを介さず、引数リストで実行する。
- `%USERPROFILE%\.git-gui-windows-app\settings.properties`の既存キー、形式、保存場所を変更しない。
- GUI確認で見つかった機能変更は、本計画に混在させず別の計画・コミットに分ける。
